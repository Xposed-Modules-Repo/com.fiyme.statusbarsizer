# FlymeStatusBarSizer

让 Flyme 的系统界面更合心意。

FlymeStatusBarSizer 是一个面向 Flyme 的 LSPosed 模块，应用内名称为 **FlymeBarSizer**。从状态栏图标、电池和时间样式，到桌面整理、最近任务和导航手势，都可以在设置界面中按需调整。首页支持功能搜索，图标设置提供预览。

[下载 APK](https://github.com/shenymo/FlymeStatusBarSizer/releases) · [反馈问题](https://github.com/shenymo/FlymeStatusBarSizer/issues) · [开源许可](LICENSE)

## 功能亮点

### 图标与电池

- **调整状态栏图标**：调节系统图标、电池数字和通知图标大小；支持用应用自身图标显示通知。
- **自定义电池外观**：提供类 iOS、类 One UI 和 iOS 旧版三种样式，可调节数字字体、镂空效果、宽高与圆角；也可开启摄像头环形电池，调整半径、粗细和彩虹色效果。
- **调整信号与 Wi-Fi**：支持单卡与双卡合并显示、自定义信号柱外观和网络类型标识，以及 Wi-Fi 图标重绘和位置交换。

### 时间与网络

- **组合时间样式**：通过按钮和拖动排序组合时间表达式，支持秒、星期、AM/PM 和传统时辰等内容，并可调整字重、字号。
- **查看详细时间**：点击状态栏时钟展开时间与日期，可显示农历，并进一步展开内存、电池、最近任务和快捷入口。
- **控制网速显隐**：分别设置显示、隐藏阈值和连续确认次数，减少低速时的频繁切换。

### 系统外观

- **按场景设置状态栏颜色**：桌面、最近任务、下拉通知栏、控制中心和锁屏可分别选择跟随系统、固定黑色或固定白色。
- **AI 整理桌面**：按应用用途生成分类，预览并调整应用归属和文件夹尺寸后应用，保留底栏、小组件及特殊快捷方式。需要自行配置 AI 接口。
- **调整卡片外观**：自定义通知卡片、最近任务卡片的圆角，以及通知背景和文字颜色选项。

### 系统交互

- **自定义 mBack**：长触可启动 URL / Intent、打开底部时间弹窗或后台应用星图；支持导航栏透明、小白条显隐及尺寸、高度调整。
- **调整小窗手势**：支持侧边手势启动自定义动作、扩展小窗选择面板环数，以及长停全屏打开。
- **编排输入法控制栏**：将返回、粘贴、撤销、删除、全选、复制、切换输入法拖入固定 7 个槽位，自由决定显示位置，并调整图标大小、透明度和背景。
- **启用 iOS 式堆叠后台**：在竖屏最近任务中使用堆叠卡片，可配置模糊、阴影和清除全部按钮；横屏保留系统布局。
- **扩展 CarLink**：扩展可流转应用，提供网易云首次加载修复、车机昼夜样式隔离等选项。

### 高级与调试

提供配置导入、导出和恢复默认，以及布局微调、环形电池位置调整、堆叠后台参数、Telephony 模拟调试、OneMind 性能调节控制和手机管家后台优化选项。

## 安装与启用

### 使用前提

- 使用 Flyme 系统，并已安装、启用支持 **libxposed API 101** 的 LSPosed 框架。
- 模块依赖 Flyme 的系统组件，具体功能会受机型和系统版本影响。目前尚未整理已验证的机型与 Flyme 版本清单。
- 应用首页的进程重启功能需要授予模块 Root 权限。

### 安装步骤

1. 从 [Releases](https://github.com/shenymo/FlymeStatusBarSizer/releases) 下载 APK 并安装；已发布版本的功能以对应版本说明为准。
2. 在 LSPosed 中启用模块，检查下表中所需功能对应的作用域。
3. 首次启用后重启手机，让模块加载到对应系统组件中。
4. 打开 **FlymeBarSizer**，通过首页功能搜索或分类页面调整设置；带有“应用”按钮的项目需要点击后保存。
5. 按下方“设置如何生效”重启对应应用，检查实际效果。

### 作用域对应表

模块声明的作用域如下，可按功能核对 LSPosed 中的启用情况。桌面、车联和输入法等功能需要对应组件已安装。

| 系统组件 / 应用 | 包名 | 相关功能 |
| --- | --- | --- |
| 系统界面 | `com.android.systemui` | 状态栏、图标、电池、时间、通知、mBack |
| 系统桌面 | `com.meizu.flyme.launcher` | AI 桌面整理、最近任务、桌面与后台场景的状态栏颜色联动 |
| SystemUITools | `com.flyme.systemuitools` | 小窗侧边手势与选择面板 |
| OneMind / PPS | `com.meizu.pps` | OneMind 性能调节控制 |
| 手机管家 | `com.meizu.safe` | 手机管家后台优化 |
| CarLink | `com.upuphone.carlink` | 应用流转与车联相关选项 |
| 系统框架 | `android` | 输入法控制栏相关功能 |
| AOSP 输入法 | `com.android.inputmethod.latin` | 输入法控制栏 |
| Gboard | `com.google.android.inputmethod.latin` | 输入法控制栏 |
| 微信输入法 | `com.tencent.wetype` | 输入法控制栏 |
| Flyme 输入法 | `flyme.inputmethod` | 输入法控制栏 |

## 设置如何生效

设置会自动保存并同步，部分项目支持即时刷新。时间表达式、输入法按钮布局等带有“应用”按钮的编辑器，需先点击“应用”。若效果未更新，可在首页“应用重启”中重启对应组件：

| 修改内容 | 首页重启入口 |
| --- | --- |
| 状态栏、图标、电池、时间、通知、mBack | SystemUI |
| 桌面外观、最近任务布局、堆叠参数 | 系统桌面 |
| 小窗相关设置 | SystemUITools |
| OneMind 性能调节 | OneMind/PPS |

桌面和最近任务的状态栏颜色涉及系统界面与系统桌面；若切换后未更新，可分别重启这两个组件。CarLink 设置需重启 CarLink。输入法和手机管家相关设置未生效时，可重启对应应用；作用域变更后可重启手机。

## 常见问题

**安装后没有效果怎么办？**

先检查 LSPosed 框架是否正常运行、是否支持 API 101，以及模块和对应作用域是否启用。重新打开模块设置，确认相关开关已开启、编辑内容已应用，再重启对应组件。若只有个别功能无效，反馈时请附上机型、完整 Flyme 版本、模块版本、复现步骤和相关日志。

**隐藏桌面图标后，如何进入设置？**

从 LSPosed 的模块页面打开设置，再到“关于与支持”关闭“隐藏桌面图标”，即可恢复桌面入口。

**AI 桌面整理如何使用？**

进入“系统外观 → AI 整理桌面”，填写兼容 Chat Completions 的完整 HTTPS 接口地址、模型名称，以及服务商要求的 API Key。依次点击“读取桌面”“生成 AI 分类”，在预览中调整分类和文件夹尺寸，最后点击“应用整理”。生成分类时会向你配置的服务发送应用名称和包名；接口配置保存在本机。

**调试页能改变实际信号或网络吗？**

Telephony 调试用于模拟插卡数量、网络类型和信号等级，以检查图标显示，不会改变实际网络连接。调试结束后可点击“恢复真实系统”。

**如何备份或恢复设置？**

在“高级与调试 → 配置管理”中导出或导入配置，也可恢复默认。恢复后若界面没有更新，重启对应组件。
